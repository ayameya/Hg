# ハードウェア接続ガイド

> **高電圧注意**　ТГ1Б の陽極回路には数十〜200 V 級の直流を使います。感電・火傷・部品破裂の危険があります。
> 通電中の回路に触れない、平滑コンデンサの放電を確認してから作業する、陽極電源に電流制限と
> ヒューズを入れる、マイコン側とは絶縁（またはグラウンド一点接続＋保護）を取る、を必ず守ってください。
> 本書の定数はすべて **出発点の目安** であり、手元の ТГ1Б のデータシートで必ず確認してください。

## 1. ТГ1Б について分かっていること

公開情報（下記出典）から確認できたのは次の範囲です。

| 項目 | 内容 |
| --- | --- |
| 種類 | 熱陰極・グリッド制御のガス入り整流管（サイラトロン）、**二陽極** |
| 封入ガス | クリプトン・キセノン混合 |
| 陰極 | 酸化物陰極・傍熱型 |
| 外形 | ガラス製サブミニチュア管、リード線端子 |
| ピン配置 | 1 = 第 1 陽極、2・5 = ヒーター、3 = グリッド、4 = 陰極、6 = 第 2 陽極 |
| 予熱時間 | 10 秒 |
| 最大平均電流 / 最大電圧 | 20 mA / 240 V（販売店の掲載値） |
| 寿命 | 500 時間以上 |

**ヒーター電圧・電流、点弧電圧、放電維持電圧、グリッド特性は今回確認できませんでした。**
必ず手元の管のデータシート（または実測）で確認してから通電してください。

出典: [155la3.ru（ТГ1Б）](http://www.155la3.ru/tg1bv.htm)、[rudatasheet.ru（ТГ1Б）](https://rudatasheet.ru/tubes/tg1b/)、
[ipelectron.ru（ТГ1Б）](https://ipelectron.ru/katalog/elektronnye_komponenty/elektrovakuumnye_pribory/tiratrony/tg1b_tiratron/)

### 予熱に関する注意

熱陰極ガス管は、陰極が十分に温まる前に陽極電圧をかけると陰極が傷みます。
ヒーターを先に点け、予熱時間（10 秒以上、余裕を見て 30 秒程度）経ってから陽極電源を入れてください。
ファームウェアの `TUBEPI_HV_ENABLE_PIN` を設定すると、起動後 `TUBEPI_WARMUP_MS` ミリ秒経ってから
そのピンを HIGH にするので、リレーやフォト MOSFET で陽極電源を投入するインターロックに使えます。

## 2. 入力方式の選び方

| 方式 | ビルド | 何を測るか | 速さの目安 |
| --- | --- | --- | --- |
| **アナログ（推奨）** | `TUBEPI_SOURCE=0` | 放電中のプラズマが出す雑音電圧を増幅して ADC で読む | 出力 1 万ビット/秒以上 |
| パルス間隔 | `TUBEPI_SOURCE=1` | 弛張発振させたサイラトロンの点弧タイミングの揺らぎ | 出力 = パルス数 / 2 ビット/秒 |

どちらも出力ビットは健全性テストとフォン・ノイマン抽出器（アナログ時）を通してから使います。

## 3. アナログ方式

### 3.1 構成

```
  +HV (電流制限付き)                                          3.3 V
     │                                                         │
    [Ra] 陽極抵抗（放電電流を数 mA に制限）                    [R] ┐
     │                                                         │   ├ Vbias
     ├──────||──────┬──────────────[ 増幅 (AC結合) ]──┬────[R]─┘
     │   Cc (高耐圧)  │                                 │
  ┌──┴──┐            [Rin]                         ショットキー
  │ A1  │             │                            クランプ ── ADC 入力
  │ТГ1Б │ G ─[Rg]─┐  GND                                   (XIAO: D1 / Pico: GP26)
  │  K  │         │
  └──┬──┘         │
     └────────────┴── GND（HV 側のマイナス）
```

1. 陰極（4 番）を HV 電源のマイナスに、グリッド（3 番）は数十〜数百 kΩ で陰極へ。
2. 第 1 陽極（1 番）を陽極抵抗 `Ra` 経由で HV プラスへ。第 2 陽極（6 番）は未接続か第 1 陽極と並列。
3. 放電電流は **最大定格 20 mA より十分小さく**（数 mA 程度から）なるよう `Ra` を決めます。
   サイラトロンは一度点弧するとグリッドで電流を止められないので、電流は必ず `Ra` で制限します。
4. 陽極の雑音電圧を高耐圧のカップリングコンデンサ `Cc`（HV の 2 倍以上の定格）で取り出し、
   単電源のオペアンプ（レール・ツー・レール出力のもの）で増幅します。
5. 増幅器出力を ADC の中点付近にバイアスし、ショットキーダイオードで 0 V〜3.3 V にクランプしてから ADC へ。

### 3.2 レベル合わせの目標

Web 画面の「ノイズ源」カードを見ながら調整します。

| 指標 | 目標 |
| --- | --- |
| 平均 | ADC 範囲の中央付近（ESP32-C3 は約 0〜2.5 V が有効範囲なので 1.2 V 前後、Pico は 1.65 V 前後） |
| 最小 / 最大 | 0 と 4095 に張り付かない（クリップしない） |
| 標準偏差 σ | 数十〜数百 LSB |
| 最小エントロピー | 4 bit/サンプル以上 |
| 系列相関 | ±0.01 以内（大きいときは `TUBEPI_ANALOG_DECIMATION` を増やす） |

### 3.3 乱数が本当に管から来ているかの確認

ADC 自体の雑音だけでもそれらしいビットは出てしまうので、次の手順で必ず確かめてください。

1. 陽極電源を切った状態（ヒーターのみ）で σ を読む。これが ADC と増幅器だけの雑音です。
2. 陽極電源を入れて放電させ、σ が **何倍にも** 増えることを確認する。
3. `TUBEPI_QUIET_SIGMA` を手順 1 の σ の 3 倍程度に設定し直す。
   これで管が放電していないときは「ノイズ不足」と判定され、ビットは捨てられます。

## 4. パルス間隔方式

### 4.1 構成

```
  +HV ──[Rc]──┬──────────── A1 (ТГ1Б)
              │
             [C]  充電コンデンサ          G ── バイアス分圧（点弧点の調整）
              │
  GND ────────┴───[Rlim]──[フォトカプラ LED]── K
                                   ┊
                         フォトトランジスタ ── パルス入力（プルアップ済み、立下りで検出）
                                               XIAO: D3 / Pico: GP15
```

1. `Rc` を通して `C` を充電し、陽極電圧が点弧電圧に達するとサイラトロンが点弧して `C` を放電、
   電圧が下がると消弧してまた充電、を繰り返す弛張発振器にします。
2. 点弧の瞬間は電離の統計的な揺らぎでばらつくので、その間隔を乱数源にします。
3. 放電電流をフォトカプラの LED に流して（`Rlim` で LED の定格内に制限）絶縁してから GPIO に入れます。
4. 発振周期は 0.5〜5 ms 程度から始め、Web 画面で間隔の σ が 2 µs を十分超えることを確認します。
   `Rc` は消弧できるだけ大きく（維持電流を保てない値）してください。消弧しないと発振しません。

### 4.2 ビットの作り方

既定では連続する 2 つの間隔 `t1`, `t2` を比べて `t1 < t2` を 1 とし、1 ビットごとに比較の向きを反転させます。
ドリフトの影響を受けにくい方法です。間隔の揺らぎが µs 単位で十分大きいときは
`TUBEPI_PULSE_BITS_LSB=1`（間隔の最下位ビットを使う）で速度が 2 倍になります。

## 5. ピン割り当て

| 信号 | Seeed XIAO ESP32C3 | Raspberry Pi Pico 2 W |
| --- | --- | --- |
| アナログ入力 | D1（GPIO3 / ADC1_CH3） | GP26（ADC0 / 31 番ピン） |
| パルス入力 | D3（GPIO5） | GP15（20 番ピン） |
| 陽極電源イネーブル（任意） | 例: D2（GPIO4） | 例: GP14（19 番ピン） |
| GND | GND | GND（例: 38 番ピン） |

変更はビルドフラグ `-DTUBEPI_ANALOG_PIN=` `-DTUBEPI_PULSE_PIN=` `-DTUBEPI_HV_ENABLE_PIN=` で行います。

- XIAO ESP32C3 の GPIO2・8・9 はストラッピングピンなので入力には使っていません。
  ADC2（GPIO5）は Wi-Fi 使用中に ADC として使えないため、アナログ入力は ADC1 のピンにしています。
- Pico 2 W の GP29 は無線チップと共用なので使いません。RP2350 の GPIO には入力リークの
  エラッタ（E9）があるため、ADC にはオペアンプ出力のような低インピーダンスの信号を入れてください。
