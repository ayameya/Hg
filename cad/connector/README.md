# 6ピン(2列×3)シェル付きコネクタ CADモデル

写真(定規を目安に採寸)から起こした近似モデルです。

| ファイル | 内容 |
|---|---|
| `connector.step` | STEPアセンブリ(シェル / ハウジング / コンタクト・ピン、色付き) |
| `connector.stl` | 一体化したメッシュ(3Dプリント・干渉確認用) |
| `connector.py` | CadQueryのパラメトリックモデル。寸法を変えて `python3 connector.py` で再出力 |
| `preview.png` | プレビュー |

## 座標系

- 原点: 嵌合面(前面)の幅方向中央、基板実装面上
- X: 幅方向、Y: 奥行方向(前面 Y=0 → 後面 Y=12.8)、Z: 高さ方向(基板面 Z=0、本体は +Z、ピン・脚は −Z)

## 主要寸法 (mm)

| 項目 | 値 |
|---|---|
| 本体 幅 × 奥行 × 高さ | 12.8 × 12.8 × 7.8 |
| シェル板厚 | 0.3 |
| 前面フランジ | 両側に外向き 0.7、Z 1.1〜6.2 |
| 底面中央の凸(U字) | 幅 4.5(下端)/ 3.2(上端)、高さ 1.3 |
| 開口の奥行(黒ハウジング前面まで) | 8.6 |
| コンタクト台 | 幅 6.2、Z 3.8〜5.3、前面から 5.0 まで突出 |
| 上面バネ爪 | 幅 1.35、中心 X = ±3.7、前面から 0.7〜7.6 |
| 側面窓 | 前面から 2.8〜5.8、Z 2.0〜5.3 |
| ピン | 2列×3本(計6本)、ピッチ 2.0、列間 2.0、断面 0.4 角、突出 2.8 |
| シェル固定脚 | 片側2本、幅 1.4、厚 0.3、突出 2.8 |

## 基板穴位置の目安

- ピン穴: X = −2.0 / 0 / +2.0、Y = 10.2 / 12.2、φ0.8 程度
- 固定脚穴: X = ±6.25、Y = 4.4 / 9.9、1.8 × 0.7 程度の長穴
- 前面フランジ(X = ±6.4〜±7.1)が基板端・筐体パネルに当たる位置に注意

## 注意

- ピン・脚の突出長は写真からの推定です。
- 内部のコンタクト形状は簡略化しています。
