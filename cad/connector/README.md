# 3ピン(2列×3)シェル付きコネクタ CADモデル

写真(定規を目安に採寸)から起こした近似モデルです。

| ファイル | 内容 |
|---|---|
| `connector.step` | STEPアセンブリ(シェル / ハウジング / ピン、色付き) |
| `connector.stl` | 一体化したメッシュ(3Dプリント・干渉確認用) |
| `connector.py` | CadQueryのパラメトリックモデル。寸法を変えて `python3 connector.py` で再出力 |
| `preview.png` | プレビュー |

## 座標系

- 原点: 嵌合面(前面)の幅方向中央、基板実装面上
- X: 幅方向、Y: 奥行方向(前面 Y=0 → 後面 Y=12.8)、Z: 高さ方向(基板面 Z=0、本体は +Z、ピンは −Z)

## 主要寸法 (mm)

| 項目 | 値 | 精度 |
|---|---|---|
| 本体幅 W | 12.8 | ±0.2 程度 |
| 本体奥行 D | 12.8 | ±0.3 程度(前端が定規の下で見えないため下限寄り) |
| 本体高さ H | 6.5 | **推定値**(真横の写真が無く、斜め写真の比率から推定) |
| 黒ハウジング奥行 | 4.2 | |
| 中央舌部の奥行(後面から) | 6.0 | 幅 3.7 |
| 窓 | 幅 3.55 × 長さ 2.7、前面から 2.9〜5.6 | |
| ピン | 2列×3本、ピッチ 2.0、断面 0.4 角、突出 2.8 | 列位置: 後面から 0.6 / 2.6 |
| シェル固定脚 | 片側2本、幅 1.4、厚 0.3、突出 3.0 | 後面から 2.9 / 8.4 |

## 基板穴位置の目安

- ピン穴: X = −2.0 / 0 / +2.0、Y = 10.2 / 12.2、φ0.8 程度
- 固定脚穴: X = ±6.25、Y = 4.4 / 9.9、1.8 × 0.7 程度の長穴

## 注意

- 嵌合面(前面の開口形状)は写真に写っていないため、外形のみのブロックとしています。
- 高さ・ピン/脚の突出長は推定値です。ノギスで実測した値を `connector.py` 冒頭の定数に入れると更新できます。
